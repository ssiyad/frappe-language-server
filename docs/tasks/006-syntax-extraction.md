# 006 — Syntax extraction

**Phase** 2 · **Depends on** — · **Blocks** 007

`frappe-syntax`: source text → unresolved matches. No index dependency, per
[02](../specs/02-architecture.md).

## Scope

- tree-sitter setup for Python, JavaScript, JSON.
- Buffer store: `ropey` + tree cache, incremental `Tree::edit` on `didChange`.
- Position conversion honouring the negotiated `positionEncoding`.
- Query-based pattern matching producing `(pattern_id, spans)`.
- Local binding inference per [06](../specs/06-analysis-pipeline.md) — bounded
  exactly as written: single function scope, literal constructors, drop on any
  reassignment, `self` binding, table-iteration binding.
- Vendored constants generated by `cargo xtask codegen`.

## Done when

Extraction unit tests pass on snippets with no bench present. The dynamic-argument
forms in [06](../specs/06-analysis-pipeline.md) yield `Anchor::Unknown`. An
incremental edit sequence yields the same tree as a fresh parse (property test).
